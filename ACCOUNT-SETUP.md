# Comptes clients
Configurer Supabase Auth par lien email, SMTP et URL de redirection exacte. Appliquer la migration SQL. Renseigner URL et clé publique dans account-config.js. Déployer checkout et stripe-webhook (ce dernier sans JWT mais avec signature Stripe obligatoire). Configurer STRIPE_SECRET_KEY, STRIPE_PRICE_ID, STRIPE_WEBHOOK_SECRET, APP_ORIGIN. Tester Stripe en mode test et deux appareils réels. Le site actuel est public et statique : les droits sont vérifiés côté serveur mais les fonctionnalités existantes ne sont pas protégées par un paywall serveur. Avant vente, déplacer les fonctionnalités payantes derrière une API autorisée, traiter remboursements/litiges, achats simultanés et récupération en cas de perte d'adresse. Tests unitaires : node --test account.test.mjs.
